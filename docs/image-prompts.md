# ChatGPT 画像制作プロンプト集（差し替え箇所ごと）

`docs/image-plan.md` で差し替え・新規追加した **11 箇所** ぶんのプロンプトです（2026-08-19 更新：モノクロ指定を外し、元の色で仕上げる方針に変更）。
そのまま ChatGPT（画像生成／画像編集）に貼り付けて使えます。
生成後は指定のファイル名で `assets/originals/` に置き、`npm run images` を実行してください
（OG 画像のみ `public/og.png` に直接配置）。

共通ルール（各プロンプトの末尾に含めています）
- 写真・実物はカラー（自然な色、過度な彩度強調なし）。図版・OG 画像だけはモノクロ（#FAFAF9 の背景、#0A0A0A の線と文字、グレーは #5A5A5A まで）
- 余計な装飾・グラデーション・影・ロゴの捏造・読めない疑似テキストは禁止
- 指定した比率・解像度で、透かし無し

## 1. Hero の人物ポートレート（`assets/originals/portrait.jpg` → `public/images/hero/portrait.*`）

※ 顔写真は **ご自身の写真をアップロードして編集** してもらいます（生成ではありません）。

```
添付した私の写真を、個人ブランドサイトのヒーロー用ポートレートとして仕上げてください。

- 出力：縦位置 3:4、1200×1600px、JPG（高画質）
- トリミング：胸元から頭頂まで。頭上に 10% 程度の余白を残し、顔が画面の上から 35% あたりに来るように
- 背景：無地のライトグレー（#E9E9E7 付近）に置き換え、被写体の輪郭は自然に残す
- 現像：カラー。肌の色を自然に、コントラストは中程度。フィルム調の粒子や強いフィルターは不要
- レタッチ：色被りの除去と軽い明るさ補正のみ。顔の形・表情・髪型は変えないこと
- 服装の色が明るすぎる場合は、背景より少し暗いトーンに調整してよい
- 文字・枠・透かしは一切入れない
```

## 2. OG 画像（`public/og.png`）

```
SNS シェア用の OG 画像を作ってください。

- 出力：1200×630px、PNG、背景 #FAFAF9
- 構成（上から）：
  1) 左上にワードマーク「Stendear」をセリフ体の細身の書体で（高さ約 60px）。添付のロゴ SVG をそのまま配置
  2) 小さな等幅の英字ラベル「IT CONSULTANT & ENGINEER — SENDAI, JAPAN」（文字色 #5A5A5A、字間広め）
  3) 見出し（日本語、ゴシック体・太め、2行、各行 61px 程度）：
     「Web・EC・クラウド・データ基盤を、」
     「企画から運用まで一人で通す。」
  4) 下部に 1px の薄い横罫線。その下に左寄せで「太田 駿之介　ITコンサルタント / エンジニア」、右寄せで等幅「stendear.com」
- 余白は左右 72px。要素は左揃えで整然と。写真・イラスト・装飾は不要
- 色は #0A0A0A と #5A5A5A のみ。グラデーション・影・角丸カードは使わない
- 日本語の字形が崩れないこと。文字は必ず指定どおりに（誤字・疑似文字は不可）
```

### 補足：プロンプトを用意していない箇所

- **OG 画像（2）と NDA 図版（3・4）だけはモノクロ指定のまま**です（UI の一部として扱うため）。それ以外の写真・実物はすべてカラーで仕上げてください。

- **ロゴ（ワードマーク）／ファビコン**：既存ロゴをベクター化して再構成済みのため、ChatGPT での再制作は推奨しません（ブランド資産の同一性を保つため、正式データはデザイナーに依頼してください）。
- **NDA 案件の図版（3・4）**：コード上は SVG（ダークモード追従）で完成しています。画像版が必要な場合のみ上記プロンプトを使ってください。
