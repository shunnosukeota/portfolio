# ChatGPT 画像制作プロンプト集（差し替え箇所ごと）

`docs/image-plan.md` で差し替え・新規追加した **10 箇所** ぶんのプロンプトです。
そのまま ChatGPT（画像生成／画像編集）に貼り付けて使えます。
生成後は指定のファイル名で `assets/originals/` に置き、`npm run images` を実行してください
（OG 画像のみ `public/og.png` に直接配置）。

共通ルール（各プロンプトの末尾に含めています）
- 配色はモノクロ（#FAFAF9 の背景、#0A0A0A の線と文字、グレーは #5A5A5A まで）
- 余計な装飾・グラデーション・影・ロゴの捏造・読めない疑似テキストは禁止
- 指定した比率・解像度で、透かし無し

---

## 1. Hero の人物ポートレート（`assets/originals/portrait.jpg` → `public/images/hero/portrait.*`）

※ 顔写真は **ご自身の写真をアップロードして編集** してもらいます（生成ではありません）。

```
添付した私の写真を、個人ブランドサイトのヒーロー用ポートレートとして仕上げてください。

- 出力：縦位置 3:4、1200×1600px、JPG（高画質）
- トリミング：胸元から頭頂まで。頭上に 10% 程度の余白を残し、顔が画面の上から 35% あたりに来るように
- 背景：無地のライトグレー（#E9E9E7 付近）に置き換え、被写体の輪郭は自然に残す
- 現像：モノクロ（グレースケール）。コントラストは中程度、肌のディテールを潰さない。フィルム調の粒子は不要
- レタッチ：色被りの除去と軽い明るさ補正のみ。顔の形・表情・髪型は変えないこと
- 服装の色が明るすぎる場合は、背景より少し暗いトーンに調整してよい
- 文字・枠・透かしは一切入れない
```

## 2. OG 画像（`public/og.png`）

```
SNS シェア用の OG 画像を作ってください。

- 出力：1200×630px、PNG、背景 #FAFAF9
- 構成（上から）：
  1) 左上にワードマーク「Stendear」をセリフ体の細身の書体で（高さ約 60px）。添付のロゴ SVG をそのまま配置
  2) 小さな等幅の英字ラベル「SYSTEMS & DATA ENGINEER — SENDAI, JAPAN」（文字色 #5A5A5A、字間広め）
  3) 見出し（日本語、ゴシック体・太め、2行、各行 61px 程度）：
     「Web・EC・クラウド・データ基盤を、」
     「企画から運用まで一人で通す。」
  4) 下部に 1px の薄い横罫線。その下に左寄せで「太田 駿之介　システムエンジニア / データエンジニア」、右寄せで等幅「stendear.com」
- 余白は左右 72px。要素は左揃えで整然と。写真・イラスト・装飾は不要
- 色は #0A0A0A と #5A5A5A のみ。グラデーション・影・角丸カードは使わない
- 日本語の字形が崩れないこと。文字は必ず指定どおりに（誤字・疑似文字は不可）
```

## 3. Works サムネイル：大手アパレルEC（NDA）の構成図（`assets/originals/work-apparel-ec.png` → 図版を画像で使う場合）

```
ECサイトのシステム構成図を、ポートフォリオのサムネイル用に描いてください。

- 出力：16:10、1600×1000px、PNG、背景 #FFFFFF
- スタイル：線画のダイアグラム。1.5〜2px の黒線（#0A0A0A）、角丸 4px の矩形、細い矢印。塗りは中央の主要ボックスのみ 6% グレー。手描き風・アイソメトリック・3D は不可
- 配置：
  - 左：「お客様（Web / スマホ）」のボックス
  - 中央（大きく）：「Salesforce Commerce Cloud」。中に小さく「SFRA ストアフロント」「カート / チェックアウト」「プロモーション / カタログ」「Jobs（バッチ連携）」「OCAPI / SCAPI」
  - 右に縦並びで 4 つ：「決済代行」「ポイント / CRM」「基幹 / 在庫」「倉庫 / 配送」
  - 中央から右の各ボックスへ矢印。矢印の上に小さな等幅ラベル「API」「API」「Jobs / Feed」「Jobs / Feed」
  - 左上に小さな等幅の見出し「ARCHITECTURE — B2C COMMERCE (NDA)」
  - 最下部に薄い罫線と小さな等幅テキスト「ROLE — PL / 要件定義 / 設計 / 開発 / テスト / リリース / 運用」
- フォントは Inter / Noto Sans JP 系のシンプルなゴシック。文字は指定どおり正確に
- 色はモノクロのみ。ロゴ（Salesforce の雲マーク等）は描かない
```

## 5. Works サムネイル：DRAWERS9 コーポレートサイト（`assets/originals/drawers9.jpg`）

※ 添付：drawers9.tokyo のトップページのスクリーンショット（1600×1000）

```
添付した Web サイトのスクリーンショットを、ポートフォリオ用のサムネイルに仕上げてください。

- 出力：16:10、1600×1000px、JPG または PNG
- 構成：無地のライトグレー（#E9E9E7）の背景の中央に、ノートPC（ベゼルの薄い、ロゴ無しの汎用的なもの）を正面やや俯瞰で置き、画面にスクリーンショットを嵌め込む。右下に重なるようにスマホ（ロゴ無し）を置き、同じサイトのモバイル表示（添付 2 枚目があればそれ、なければ PC 画面を縦に再構成）を表示
- デバイスは黒または濃いグレー。反射・光沢・強い影は入れない（接地面にごく薄い影のみ可）
- 全体をグレースケールで書き出す（画面内も含む）
- 画面の内容を改変・捏造しない。文字や枠、透かしは追加しない
```

## 9. About の環境写真（a）作業デスク（`assets/originals/about-desk.jpg`）

```
フリーランスのエンジニアの作業デスクを写した写真を生成してください（人物は写さない）。

- 出力：3:2、1800×1200px、JPG
- 被写体：木製または白いデスクの上に、ノートPC（閉じているか、画面は消灯）、A4 の建築図面かノート、鉛筆、コーヒーのマグ。小物は 3〜4 点までで整然と
- 構図：斜め 45° から、やや俯瞰。手前の小物を軽くぼかし、奥行きを出す
- 光：窓からの柔らかな自然光（午前中）。強い影やフレアは無し
- 仕上げ：モノクロ（グレースケール）、中程度のコントラスト。フィルム粒子なし
- 画面内に読める文字・ブランドロゴ・人物・手は入れない。透かし不可
```

```
- 仕上げ：モノクロ（グレースケール）、落ち着いたコントラスト
- 文字・看板・ロゴ・車のナンバーは写さない。透かし不可
```

### 補足：プロンプトを用意していない箇所

- **ロゴ（ワードマーク）／ファビコン**：既存ロゴをベクター化して再構成済みのため、ChatGPT での再制作は推奨しません（ブランド資産の同一性を保つため、正式データはデザイナーに依頼してください）。
- **NDA 案件の図版（3・4）**：コード上は SVG（ダークモード追従）で完成しています。画像版が必要な場合のみ上記プロンプトを使ってください。
